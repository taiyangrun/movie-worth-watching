# 电影值不值得看 🎬

免费观影决策助手。先做 6 道题摸清你的口味，再查豆瓣/猫眼/淘票票/IMDb 多平台评分，用大模型提炼评价里的亮点、槽点和**争议点**，最后给你"冲/可看/等流媒体/别看"的个性化建议。

## 怎么用

把 `SKILL.md` 导入支持 Skill 的 AI 客户端，然后说："《沙丘3》值不值得看？"

第一次会先做 6 道口味测试题（类型偏好、节奏、烂尾容忍度、雷点等），生成你的口味画像，之后直接复用。

## 工作流程

```
口味测试 → 查多平台评分 → 评价深度总结（亮点/槽点/争议点） → 个性化建议 → 购票省钱攻略
```

## 核心设计

- **同样的 7.5 分，对不同人结论完全不同**：爽片派和文艺派看到的建议可以完全相反
- **争议点是灵魂**："喜欢 X 的人狂吹，讨厌 Y 的人狂骂，你是哪类"——帮你对号入座
- **不编分**：查不到就明说；不剧透关键剧情
- **购票只给攻略**：新人券、周三会员日、银行 9 元观影等真实省钱姿势，不编实时票价
